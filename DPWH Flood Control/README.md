File Format: Parquet
Coverage: DPWH projects from 2016–2025

The dataset contains DPWH projects implemented from 2016 to 2025. For this analysis, projects were filtered to include records whose project category contains “Flood”, focusing specifically on flood control-related projects.

Key Data Observations and Limitations
Project Status: All records are tagged as Completed. Having actual project status categories such as Not Started, Ongoing, Delayed, and Completed would provide better visibility into project implementation and delays.
Amount Paid: The Amount Paid field is recorded as 0 for all projects. Populating this field with actual payment data would enable analysis of:
Budget vs. actual expenditure
Payment rate
Financial utilization
Underspending or overspending
Regional and project-level spending distribution
Project Progress: All projects are reported at 100% progress. More granular and historical progress data would help identify project delays, implementation trends, and whether reported completion aligns with actual project timelines.
Location: The geographic information is limited primarily to region and province. Adding municipality/city and barangay-level information would provide greater spatial granularity and allow analysts to identify specific communities receiving flood control investments.
Transparency Information: The dataset would provide greater transparency and accountability if fields for project images, video documentation, livestreams, or other project evidence were consistently populated and publicly accessible.

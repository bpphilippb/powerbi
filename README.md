# powerbi

Welcome Bitcoin price prediction using the native Power BI forecasting.

A quick look on bitcoin price trajectory. It uses the native Power BI forecasting tool of the line chart visual.

Dataset: Bitcoin historical data with 1minute intervals from 2012 to August 28 2026
Source: https://www.kaggle.com/datasets/mczielinski/bitcoin-historical-data?resource=download
Filetype: csv
Cleansing / Transformation - Converted Timestamp column to local date format from unix format 

Tools/Technique: Power BI, ETL, Dax Query, Star Schema, Data Modelling

Enjoy Thank you.
